Bienvenida

Aprende construyendo

En este campus encontrarás actividades prácticas para aprender a crear páginas web estructuradas, comprensibles y visualmente coherentes.

Los contenidos están organizados de manera progresiva. Puedes comenzar por los fundamentos de HTML, continuar con CSS y terminar incorporando comportamiento con JavaScript.

Antes de comenzar

Necesitarás un editor de código, un navegador actualizado y ganas de experimentar.

Actividad voluntaria

Reto de la semana

Crea dos temas visuales diferentes modificando únicamente los valores de las variables CSS declaradas en :root.

  1. Define variables para colores, espaciados y bordes.
  2. Utiliza las variables en toda la hoja.
  3. Guarda una combinación clara y otra oscura.
  4. Comprueba que el contenido sigue siendo legible.

Ayuda

Preguntas frecuentes

¿Puedo modificar el HTML?

Solo cuando el enunciado lo permita. Intenta resolver primero el diseño mediante CSS.

¿Puedo utilizar !important?

No. Debes resolver los conflictos comprendiendo la cascada y la especificidad.

¿Puedo utilizar Flexbox o Grid?

No en esta actividad. Esos sistemas de maquetación se estudiarán en próximos bloques.

¿Cómo sé qué regla está ganando?

Inspecciona el elemento y revisa las reglas aplicadas y el panel de estilos calculados.
